# BASELINE 디자인 규칙 (v1~v3에서 지킬 것)

v0에는 아직 없는 화면(포트폴리오, 모순 경고, AI 근거 검토)에 적용할 규칙. 토큰은 `src/styles.css` 상단에 이미 정의되어 있다.

## 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | #1B1F26 | 본문. **수익률 숫자도 이 색.** 부호(+/-)만 남기고 초록/빨강 등락색을 쓰지 않는다 |
| `--ink-muted` | #777777 | 보조 텍스트, [그래도 저장] 텍스트 링크 |
| `--accent` | #2F4A3F | 원칙 일치도 바, 채택 상태, 주요 CTA 강조 |
| `--warn` | #8A6A2F | 모순 경고. 빨강 금지. 비난이 아니라 환기 |
| `--navy` | #17243A | 제목, 기본 버튼 |
| `--paper` | #FBFBF9 | 카드·종이 배경 |

이유: 수익률이 주인공이 아니다. 등락에 색을 칠하는 순간 증권 앱이 되어 포지셔닝이 무너진다.

## AI 근거 검토 화면 (v3) — 버튼 구조

```
[한 줄 답하고 저장]   큰 버튼, --accent 배경, 강조
[그래도 저장]         작은 텍스트 링크, --ink-muted, 하단
```

- [그래도 저장] 클릭 시 확인 모달을 **1회만** 띄운다. 문구는 `src/lib/copy.ts`의 `COPY.followupSkipModal`을 그대로 쓴다.
- 모달에서도 저장을 누르면 통과시킨다. 절대 막지 않는다.
- 저장 시 `ai_followup_answered = false`로 기록하고, 이력 화면에는 `COPY.historyUnansweredLabel`("역질문에 답하지 않고 변경")을 중립적으로 표시한다. 비난 문구 금지.

## 타이포

- 제목/본문: `"Hahmlet", "Cormorant Garamond", serif` (Google Fonts, OFL), 본문 line-height 1.8
- 작은 라벨/숫자/버튼: `"Pretendard", sans-serif`
- 라틴만 단독으로 쓰는 요소(브랜드, 대가 영문명, kicker)만 Cormorant Garamond 우선. 한글과 섞이는 줄은 Hahmlet이 라틴까지 렌더링해 크기 균형을 맞춘다.

## 이미지
